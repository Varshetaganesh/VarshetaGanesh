## 🚀 Featured Projects

### 🏃 [SportsAI+ / StrideWise — AI-Based Smart Sports Coaching & Performance Enhancement System](https://github.com/Shreyas-GowdaSR/sports_plus)

**Collaborative Academic Project | AI/ML | Computer Vision | Sports Analytics**

An intelligent sports coaching platform designed to make personalized running-form analysis, training recommendations, and nutrition guidance more accessible.

**Key Highlights:**
- Built a browser-based running-form analysis workflow using **MediaPipe Pose** and 33 body landmarks.
- Applied pose-based movement analysis, joint-angle estimation, and posture assessment.
- Explored video-quality validation and camera-view assessment for reliable analysis.
- Integrated AI-assisted coaching and sports nutrition features.
- Worked with a **React.js and TypeScript frontend**, with backend integration using Supabase.
- Conducted related research on **vertical Ground Reaction Force (vGRF) estimation** using gradient-boosted machine learning.

**Research Results:**
- Dataset involving **39 runners**
- **R² Score:** 0.958
- **Mean Absolute Error:** 1.263 N/kg
- **39% error reduction** compared with a linear baseline
- Participant-aware evaluation to assess generalization to unseen runners

**Tech Stack:** Python, MediaPipe, React.js, TypeScript, Supabase, Machine Learning, Gemini API

🔗 **[View Team Repository](https://github.com/Shreyas-GowdaSR/sports_plus)**

> The GRF estimation work is a separate research component and should not be interpreted as a validated GRF predictor operating directly on phone video.

## 🔬 Research & Technical Exploration

### Ground Reaction Force Estimation Using Machine Learning

Explored machine learning approaches for estimating **vertical Ground Reaction Force (vGRF)** from running biomechanics data.

| Metric | Result |
|---|---|
| **Dataset** | 39 Runners |
| **Model** | Gradient-Boosted Regression |
| **R² Score** | 0.958 |
| **MAE** | 1.263 N/kg |
| **Improvement** | 39% Error Reduction vs. Linear Baseline |

**Research Focus:**
- Biomechanical feature engineering
- Participant-grouped validation
- Model generalization to unseen runners
- Regression performance evaluation
- Comparison with baseline models
- Applications of machine learning in sports biomechanics
